# Học Tập

A local FastAPI + React PWA that turns scanned Archimedes "Hướng dẫn học Toán" books
into spoken, interactive practice. One server serves the app at `/` and the API at
`/api/v1` on a single origin.

## Layout

```text
backend/           uv project, Python 3.14, package `hoctap`
  hoctap/
    content/ learning/ parent/ builder/   domain modules (filled in by later stories)
    api/           routers (no logic), error envelope, SPA serving
    db/            SQLite engine (WAL) and Alembic migrations
  tests/
frontend/          Vite + React + TypeScript PWA
  src/api/         schema.d.ts is generated by `npm run gen:api`; never hand-write API types
data/              gitignored: hoctap.db, logs/, assets/ (created on first start)
Sach_Arch/         source PDFs, read-only
```

## Requirements

- [uv](https://docs.astral.sh/uv/) (installs Python 3.14 on first `uv sync`)
- Node.js 24 LTS

## Configuration

Optional. Copy `hoctap.toml.example` to `hoctap.toml` (gitignored). `HOCTAP_DATA_DIR`,
`HOCTAP_HOST`, `HOCTAP_PORT`, `HOCTAP_LOG_LEVEL`, `HOCTAP_FRONTEND_DIST`,
`HOCTAP_SOURCE_DIR` (source PDFs, default `Sach_Arch/`), `HOCTAP_TLS_PORT` and
`HOCTAP_TLS_CERT_DIR` override the file; `HOCTAP_CONFIG` selects another file. Secrets such
as `ANTHROPIC_API_KEY` come from the environment only.

For HTTPS on the home LAN (so the tablet gets full PWA install/offline features) and
running the server natively on Windows, see
[docs/https-and-windows-setup.md](docs/https-and-windows-setup.md).

## Development commands

Backend (from `backend/`):

```sh
uv sync                              # create .venv and install pinned dependencies
uv run pytest -q                     # tests
uv run ruff check .                  # lint
uv run hoctap serve                  # http://localhost:8000 (flags: --host, --port)
uv run hoctap export-openapi         # write frontend/openapi.json for offline gen:api
uv run hoctap build catalogue        # check the Toán PDFs and upsert the book catalogue
uv run hoctap certs --ip <lan-ip>    # mkcert-signed cert for HTTPS on the LAN
uv run hoctap install-windows        # add a Windows Firewall rule for the TLS port
```

Frontend (from `frontend/`):

```sh
npm ci
npm run gen:api     # regenerate src/api/schema.d.ts from the running server, else openapi.json
npm run dev         # Vite dev server; proxies /api to localhost:8000
npm run build       # type-check and build dist/ (service worker + manifest)
npm run test        # Vitest (single run)
npm run lint        # ESLint
```

After changing any API route or model: `uv run hoctap export-openapi` in `backend/`, then
`npm run gen:api` in `frontend/`, and commit both `openapi.json` and `src/api/schema.d.ts`.

## Running the app

```sh
cd frontend && npm ci && npm run build
cd ../backend && uv sync && uv run hoctap serve
```

Open `http://localhost:8000/`. On start the server creates `data/`, the SQLite database
`data/hoctap.db` (WAL mode) and runs Alembic migrations to head. Logs are JSON lines in
`data/logs/hoctap.log`. If `frontend/dist` is missing, `/` answers
`503 {"error":{"code":"FRONTEND_NOT_BUILT",...}}` and the API still works.

New migration (from `backend/`):

```sh
uv run alembic -c hoctap/db/alembic.ini revision -m "describe change"
```
